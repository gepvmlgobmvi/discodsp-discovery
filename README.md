## Overview

Discovery Pro emulates the Nord Lead 2 Red synthesizer architecture with VA oscillators, a 24dB Moog-style ladder filter, polyphonic arpeggiator, and faithful reproduction of the Nord's analog warmth.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **discoDSP Discovery** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **VA Oscillators** | Sawtooth, square, triangle, and sine oscillators with PWM |
| **Moog Ladder** | 24dB resonant ladder filter matching Nord Lead 2 Red filter character |
| **Poly Arp** | Polyphonic arpeggiator with six modes and latch in host BPM sync |
| **Mod Matrix** | 26-slot modulation matrix with configurable source and destination |
